                - config

    3. Use your type-safe config

        Now, you can access the configuration anywhere in your server-side code:

        ```ts
        import { config } from "./config";

        config.appURL; // string => "http://localhost:3000"
        config.port; // number => 3000
        ```

## Compatibility

| Requirement     | Detail                                                       |
| --------------- | ------------------------------------------------------------ |
| Zod             | v4 — bundled, and re-exported as `z`                          |
| Parser packages | `@layerfig/parser-*` v6 pairs with `@layerfig/config` v3      |
| Module formats  | ESM and CommonJS on the server; ESM only for `/client`        |
| Runtime         | Any runtime with `node:fs` and `node:path` — see [Deno](/guides/deno/) |

<Aside>
  The parser packages are versioned independently of `@layerfig/config`, so the
  major numbers differ on purpose: `@layerfig/config@3.x` works with
  `@layerfig/parser-yaml@6.x`, `@layerfig/parser-toml@6.x` and
  `@layerfig/parser-json5@6.x`. Each parser declares
  `"@layerfig/config": "^3.0.0"` as a peer dependency.
</Aside>

<Aside type="tip">
  Only `FileSource` needs `node:fs`. The [client
  builder](/setup/configuration-client/) is pure JavaScript and runs anywhere.
</Aside>
